## Как соотносится с уже применённой на сайте палитрой "Glam Dark"
На сайте (`../assets/brand/kiselevy-creo-palette.css`) уже стоит палитра чёрный +
пыльно-фиалковый (`#0A0A0C` / `#C9BCE0` / `#B39DD8` / `#9C86C9`). Эта, снятая с фото —
того же духа (приглушённый дымчатый мов/слива), но НЕ идентична по хексам.

фото. Если нужно перекрасить сайт именно под эти тона с фото (а не под прежний
Glam Dark) — сказать отдельно, сделаю.
