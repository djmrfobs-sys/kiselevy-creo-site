# Шрифты KISELEVY CREO

Утверждено: 2026-09-01. Использовать эту пару всегда для бренда KISELEVY CREO
(сайт и другие продукты).

## Заголовки: Space Grotesk

Геометричный, современный, тот же характер, что у платных TT NEORIS / KMR APPARAT,
но бесплатный и с полной поддержкой кириллицы.

Применяется: h1, h2, h3, лого в шапке сайта.

## Текст: Inter

Рабочая база для основного текста, эталонная кириллица, отличная читаемость.

Применяется: весь остальной текст сайта (body).

## Подключение (Google Fonts)

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@500;700&family=Inter:wght@400;500;600;700&display=swap" rel="stylesheet">
```

```css
h1,h2,h3,.logo{font-family:'Space Grotesk', 'Segoe UI', Roboto, Arial, sans-serif}
body{font-family:'Inter', 'Segoe UI', Roboto, Arial, sans-serif}
```

Уже применено на сайте: `../index.html`.
