# Проект: Kiselevy Creo — портфолио-визитка Артура

## Задача
Разработать личный сайт-визитку (одностраничный лендинг) Артура Киселёва —
позиционирование как «цифровой бутик KISELEVY CREO»: боты, сайты, нейропомощники, автоматизация бизнеса.
Творческую часть (DJ LightJockey, художник по свету) на сайт НЕ выносить —
прямое решение клиента.

## Текущий статус
Готов первый черновик `index.html` (одностраничник, инлайн CSS, брендовая
палитра). Без фото (клиент пришлёт позже — сейчас плейсхолдер с инициалами
«АК»), без формы сбора контактов (не нужна), портфолио/кейсы — плейсхолдер
«скоро» (кейсов ещё не давал).

## Структура страницы (согласована)
Hero → Обо мне → Команда → Услуги → Портфолио → Технологии → Контакты
Детали и открытые вопросы — см. `knowledge/структура-сайта.md`.

## Контакты на сайте
- Личный Telegram: @KISELEVY_CREO (кнопка «Написать в Telegram»)
- Канал: @Kiselevy_Creo_digital
- Других соцсетей клиент пока не называл — уточнить, нужны ли

## Файлы в этой папке
- `index.html` — текущий черновик сайта
- `Артур-Киселёв-профиль.md` — полный профиль клиента (кто он, стек, бизнес, реквизиты)
- `knowledge/структура-сайта.md` — структура блоков + открытые вопросы
- `knowledge/о-клиенте.md` — краткий бриф для сайта
- `knowledge/прайс и услуги/kiselevy-creo-answers.md` — прайс-лист и продающие формулировки услуг

- `research.md` — референсы: как устроены сайты-визитки экспертов на рынке РФ, рекомендации по дизайну и текстам

## Открытые вопросы (спросить у клиента при продолжении)
- Конкретные кейсы/проекты для блока «Портфолио»
- Нужны ли ещё соцсети кроме двух Telegram-ссылок
- Имя супруги для карточки в блоке «Команда» (сейчас без имени, роль: продюсер/аналитик/маркетолог)
- Финальный порядок блока «Команда» (сейчас после «Обо мне», обсуждался вариант — после «Портфолио»)
- Фото для Hero и команды (клиент пришлёт позже)

## Как продолжать в новой сессии
1. Прочитать этот файл — здесь весь контекст задачи
2. Открыть `index.html` — посмотреть текущее состояние вёрстки
3. Свериться со списком открытых вопросов выше — если что-то из этого клиент
   уже дал в новом сообщении, обновить `knowledge/структура-сайта.md` и сам сайт
4. Не путать эту папку с другими проектами — все правки только внутри
   `~/projects/Kiselevy Creo/`
