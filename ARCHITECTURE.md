# Архитектура сайта KISELEVY CREO
## The Best of The Best — 28 июля 2026

### 📐 Структура
Многостраничный SPA на одном HTML-файле (для скорости):
- Все страницы переключаются через JS без перезагрузки
- SSR-ready: при желании легко разбить на отдельные файлы

### 🏗️ Страницы
1. **Главная (Home)** — Hero с загрузчиком, заголовком, CTA, статистикой
2. **Услуги (Services)** — 6 карточек услуг с иконками
3. **Портфолио (Work/Portfolio)** — галерея проектов с фильтрами
4. **О нас (About)** — Артур + Кети, история, ценности
5. **Галерея (Gallery)** — сетка изображений (референсы, работы)
6. **Контакты (Contact)** — форма, соцсети, каналы
7. **FAQ / Чат-бот** — встроенный виджет Telegram-бота

### 🎨 Дизайн-система
**Цвета** (из твоего HTML):
- Базовые: cream (#fbfbf8), ice (#dcedf6), sky (#8fc9e8), peach (#ffe3ca)
- Акцент: sky-deep (#3d8fb5), peach-deep (#f2733a), peach-warm (#ffab72)
- Текст: ink (#1c2b33), ink-soft (#5b6c74), ink-faint (#93a3aa)
- Тёмная тема: через data-theme="dark" — переопределение тех же токенов

**Шрифты:**
- Display: Bricolage Grotesque (заголовки)
- Body: Plus Jakarta Sans (текст)
- Mono: JetBrains Mono (цифры, код, технические элементы)

### 🌐 Двуязычность
- RU/EN переключатель в хедере
- Все тексты хранятся в JS-объекте `LANG`
- Переключение без перезагрузки страницы
- i18n: динамическая подмена текста по data-i18n атрибутам

### ⚡ Оптимизация скорости (< 2 сек)
- Preload критических ресурсов
- Lazy loading для изображений (loading="lazy")
- Отложенная загрузка невидимых секций (Intersection Observer)
- CSS анимации через GPU-акселерацию (transform, opacity)
- Font-display: swap (шрифты не блокируют рендер)
- Минимум внешних запросов (Google Fonts preconnect)
- NO тяжелых библиотек: чистый HTML/CSS/JS

### 🎬 Анимации (как у Linear/Stripe)
- Loader-экран (как "занавес")
- Kinetic words в заголовке (анимация по словам)
- Параллакс космических сфер (cosmic-orb)
- Scroll reveal для секций
- Бургер-меню с плавным открытием
- Карточки с hover-эффектами (translateY, shadow)
- Page transition при переключении страниц (как у Vercel)

### 🤖 Telegram-бот помощник
- Бот: @Site_Kiselevy_Creo_bot (токен получен)
- Отвечает на вопросы о компании
- Команды: /start, /about, /services, /contact, /portfolio
- Виджет на сайте через Telegram Web Widget
- Inline mode для встраивания

### 🌍 Хостинг
**Cloudflare Pages** — почему:
- Бесплатно (100GB трафика/месяц)
- CDN в 330+ городах мира
- Работает в РФ (Cloudflare — единственный крупный CDN, который не ушёл)
- HTTP/3, Brotli сжатие, кеширование
- Автоматический деплой с GitHub
- SSL автоматически
- Можно привязать и .ru и .com домены

**Домен:** стратегия
- Основной: kiselevy-creo.com (для всего мира)
- Редирект/зеркало: kiselevy-creo.ru (для РФ)
- Или: .com работает везде — можно ограничиться им

### 🎯 Критические элементы (с Linear/Notion/Stripe)
1. **Hero с градиентом** — как у Linear (тёмная/светлая тема)
2. **Интерактивный элемент** — как Vercel (но без сервера)
3. **Социальные доказательства** — как Stripe (логотипы)
4. **Минималистичный хедер** — как Notion
5. **Плавные переходы между страницами** — как Awwwards-сайты
6. **Двуязычность** — мгновенное переключение
7. **Мгновенная загрузка** — preconnect, preload, lazy, IntersectionObserver
8. **Виджет чат-бота** — Telegram Web Widget
