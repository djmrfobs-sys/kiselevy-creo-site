# Research: сайты-визитки экспертов на российском рынке

Собрано: 2026-08-27. Цель — референсы для портфолио-визитки Артура (KISELEVY CREO).

## Методологическая оговорка
Живых примеров личных сайтов конкретных российских экспертов (не агентств) в
открытом поиске немного — рынок фрагментирован (Tilda-конструкторы, статьи на
VC.ru, агентские кейсы). Ниже — 6 проверяемых конкретных сайтов/источников +
2 методические статьи от практиков.

## 1. Конкретные примеры

### ivantitov.tech — Иван Титов, разработчик/консультант 1С + вайб-кодинг
- Структура: sticky-навигация → Hero (текст слева / визуализация кода справа)
  → About (2-3 колонки) → Projects/Products (grid карточек) → Blog → Contacts+форма
- Стиль: тёмная тема (фон #0a0a0f/#12121a/#1a1a26), акценты cyan-blue #00e5ff и
  purple #7b61ff, CTA оранжевые #ff6b35. Шрифты Unbounded + JetBrains Mono
- Hero: «Консультант в 1С» + анимация набора кода
- Обо мне: акцент на цифрах — 15+ лет опыта, 200+ проектов, стек (React,
  HTML/CSS/JS), не на личности
- Сделан вайб-кодингом (чистый HTML/CSS/JS, без фреймворков) — прямая
  релевантность профилю Артура

### bitmap.ru — Антон «Битмап» Черкасов, частный веб-дизайнер/фрилансер
- Структура: меню (О себе/Услуги/Портфолио/Статьи/Контакты) → Hero с 4
  карточками услуг → автор → галерея свежих работ → детальные секции услуг →
  география → статьи → контакты
- Hero: «Создание сайтов. Веб дизайн» + оффер + CTA «Подробней об услуге»
- Самопрезентация: от первого лица, коротко, без пафоса — «Я — Антон
  "БИТМАП" Черкасов — частный веб-мастер...»
- Классический многостраничник (не одностраничный лендинг)

### Портфолио на Tilda (частные примеры)
katerina-stepanova.com (VR-специалист), photographika.ru (фотограф),
advokat-kalugin.ru (частный юрист) — общий паттерн: одна специализация в
фокусе, минимум разделов (обо мне, портфолио, контакты)

## 2. Методические источники (рекомендации практиков)

### tpverstak.ru — «Сайт-портфолио для верстальщика и фронтенд-разработчика»
Структура: Hero (фото, имя, кнопка резюме) → About Me (фото + диаграмма
навыков + личные факты) → Skills → Портфолио (кейсы со скриншотами,
описанием, отзывами) → Контакты/соцсети. Совет: «обо мне» — просто, с пользой
для клиента, по подзаголовкам

### vc.ru — опыт эксперта (HappyAtWork)
Структура: About (достижения) → Книги → Блог → Ресурсы → Услуги → Календарь
выступлений + CTA «Book me». Личное фото на главной, логотипы клиентов как
соцдоказательство

### tsukanovdesign.ru — «Сайт для эксперта и личного бренда»
Структура: Hero → Trust-блок (регалии, публикации) → Услуги (что
входит/сроки/цена) → Кейсы по схеме «запрос → что делали → результат» →
Блог → Запись/контакты через Telegram. Регалии подаются как польза для
клиента, не список наград

## 3. Общие паттерны

1. Hero = роль + УТП, не просто имя крупным планом
2. «Обо мне» через цифры и специализацию, а не лирику (годы опыта, число
   проектов, конкретный стек/ниша)
3. Тёмная минималистичная тема — частый выбор у IT/разработчиков; у
   дизайнеров-фрилансеров чаще светлая
4. Портфолио через кейсы по формуле «запрос → что делали → результат», не
   просто галерея скриншотов
5. Соцдоказательство: логотипы клиентов, отзывы, регалии — почти всегда
6. CTA — конкретное действие («Скачать бриф», «Book me», запись через
   Telegram), не абстрактное «написать мне»
7. Одностраничник с якорной навигацией — стандарт для персонального сайта;
   многостраничники (bitmap.ru) — более старый подход
8. Блок «Технологии/навыки» отдельным визуальным элементом — почти всегда у
   технических экспертов

## 4. Рекомендации для сайта Артура

Палитра клиента (персик #e8b593 / бежевый #e9ddd0 / терракота #d9986f /
кофейный текст #5c4033) — тёплая, «уютная», нетипичная для IT-неона.

1. **Hero: роль + конкретный оффер, не просто имя.** По аналогии с
   ivantitov.tech и bitmap.ru — заголовок должен называть, что именно
   делает Артур и для кого, а не только «Артур Киселёв». Тёплая палитра —
   отличие от типового чёрного техно-стиля конкурентов
2. **«Обо мне» — цифры + специализация, коротко.** 2-4 предложения,
   факт → польза для заказчика, без лирики
3. **Портфолио — по формуле кейсов**, не голая галерея: «запрос → что
   сделали → результат» для каждого проекта
4. **Блок «Технологии» — визуальные бейджи/иконки стека**, отдельно от
   «Услуг». Стоит явно показать AI-инструменты (Claude, Cursor и т.п.) —
   отличает от «обычных» разработчиков, в тренде рынка вайб-кодинга
5. **CTA — конкретное действие с низким трением**, например «Обсудить
   проект» с прямой ссылкой на Telegram — вместо абстрактного «Связаться».
   Кнопки терракотового/персикового цвета впишутся органично

## Что не проверено
- Сайты российских маркетологов/таргетологов и коучей — только фрагменты
  через Tilda-подборки, не изучены детально
- Сайты продюсеров экспертов (блок «Команда» специфичен для
  продюсерских/студийных лендингов) — ниша слабо представлена в открытом
  поиске
- romanvaskov.github.io/portfolio — найден по названию, содержимое не
  проверено
