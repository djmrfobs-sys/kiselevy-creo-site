# Тренды Instagram под контент KISELEVY CREO

Задача (поставлена 2026-09-01): каждый день парсить Instagram по теме Артура
(AI-агенты, нейро-агенты, боты, сайты, автоматизация) и присылать ролики,
которые залетают в топ и набирают просмотры — для вдохновения на собственные
Reels.

## Статус

Нужен `APIFY_TOKEN` (сервис парсинга) — пока не добавлен через /settings.
Артур присылал токен текстом в чат дважды (2026-09-01), оба раза отклонил
по правилам безопасности (ключи в чат не принимаются, только через /settings).

Как только токен появится в окружении — включаю ежедневную задачу на реальных
данных Instagram Scraper (Apify).

## Второй запрос: видео с лицом Артура

Артур также попросил, чтобы агент сам монтировал/генерировал видео с его лицом
по мотивам залетевших трендов, для соцсетей.

Честно зафиксировано: сейчас в системе нет ни одного инструмента для генерации
видео с лицом человека (AI-аватар/talking-head) — проверены переменные
окружения на HeyGen, Synthesia, D-ID, Runway, Kling, Luma, Pika — ни одного ключа
нет. Без такого сервиса это невозможно технически, а не "лень" агента.

Что нужно для реализации:
- Ключ одного из сервисов генерации говорящего аватара (HeyGen, Synthesia, D-ID)
  — Артур один раз записывает короткий референс своего лица/голоса, дальше
  сервис генерирует видео по тексту сценария.
- Либо монтаж без AI-аватара: агент пишет сценарий/хук по тренду
  (скилл `scenario-writer`), а Артур сам снимает по нему — тоже рабочий путь,
  не требует новых ключей.

Обсуждено с Артуром 2026-09-01, ждём решения — какой путь выбрать.
